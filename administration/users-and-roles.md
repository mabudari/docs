## The roles

| Role | Intended for |
|---|---|
| **Super administrator** | Full control, including cluster-level settings |
| **Administrator** | Day-to-day administration |
| **Operator** | Running workloads, without changing the platform |
| **Viewer** | Read-only |
| **API** | Machine access through an [API key]({{ '/administration/api-keys/' | relative_url }}) |
